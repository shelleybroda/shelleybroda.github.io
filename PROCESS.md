# Building the portfolio with AI

## September 28, 2026

**Research:** Reviewed two established personal websites, GitHub’s own documentation, and W3C accessibility guidance. Chose clear professional positioning, selected experience, a full résumé, direct contact links, and responsive layouts.

**Content:** Used Shelley Broda’s résumé updated July 16, 2026. Kept the roles, dates, education, GPA, and recognition grounded in that source. Emphasized legal analysis, communications, and leadership. Did not invent project outcomes, numerical impact, or work samples.

**Implementation:** Used plain HTML and CSS. This keeps the site easy to understand, quick to load, and compatible with GitHub Pages. The first design slice included the introduction and education; the next added selected experience, leadership, skills, contact information, and a separate full résumé.

**AI tool:** OpenAI Codex handled research, drafting, coding, and refinement. GitHub’s connected tools provide access to repository content. The user remains the source for personal facts, photo selection, and the recorded class presentation.

**Design choices:** Navy establishes a professional tone; blue provides emphasis. Serif headings give the site a distinct identity. Selected experience uses a consistent date/role/description structure so a hiring reader can scan quickly.
