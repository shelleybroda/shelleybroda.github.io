# Portrait

Shelley Broda supplied the original portrait and requested removal of its photographer watermark on October 13, 2026. OpenAI’s built-in image editing tool removed the overlay with instructions to preserve her identity, expression, pose, clothing, background, and lighting. This is an AI-edited version of the supplied real photograph.

The edited master was resized and encoded into metadata-free web images:

- `shelley-broda-480.webp`: 480 × 650, 20,528 bytes.
- `shelley-broda-800.webp`: 800 × 1083, 44,220 bytes.
- `shelley-broda.jpg`: 800 × 1083, 87,734 bytes, progressive JPEG fallback.

The responsive `picture` element lets the browser choose a WebP resolution for its viewport and pixel density. The previous PNG was 1,112,891 bytes. The original and edited master are retained outside the published site; the original is also recoverable in Git history.
